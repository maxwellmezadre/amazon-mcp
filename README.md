# amazon-mcp

CLI + servidor MCP para o histórico de compras da **Amazon.com.br**: pedidos,
produtos, preços, parcelamento, notas fiscais e resumos de gastos, com cache
local em SQLite.

> **Somente leitura.** Nenhuma tool escreve na sua conta da Amazon.

Em construção. Veja `docs/` quando a v0.1 sair.
